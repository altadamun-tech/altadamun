# واجهة دخول الموارد البشرية

تستخدم هذه الواجهة إعداد Firebase المشترك في `../../js/firebase-config.js`. يتطلب الدخول حسابًا فعالًا بدور IT. تطبيق الموظفين والإجازات والرواتب يوجد في `../hris`.

لتجميع الواجهة الاختيارية، اضبط `NEXT_PUBLIC_BASE_PATH` على مسار نشرها إن لزم، واضبط `NEXT_PUBLIC_HRIS_PATH` على رابط تطبيق الموارد البشرية ضمن المصدر نفسه. شغّل `npm ci` ثم `npm run build`. المخرجات الثابتة في `out/`. حزمة GitHub Pages الرئيسية تستخدم تطبيق Vite مباشرة.
